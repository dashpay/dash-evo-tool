PasswordInput Component

Interactive wireframe -- Dash Evo Tool design system

How to interact: Hold down the mouse button on the eye icon to reveal the password. Release the mouse button or move the cursor away from the icon to re-mask. This is a hold-to-reveal pattern, not a toggle.

1. All Component States

Default (empty with hint)
With value (masked)
Error state
Incorrect password
Disabled

2. Use Case: Wallet Unlock

Persona: Alex (everyday user) unlocking a wallet to send Dash.

3. Use Case: Private Key Input (monospace)

Persona: Priya (power user) importing a private key in WIF format.

4. Use Case: Dynamic Key List (Add Existing Identity)

Persona: Jordan (developer) adding multiple private keys to an identity. Each key input has its own eye icon.

5. Eye Icon Geometry (painter primitives)

Both icons are drawn with egui's ui.painter() using quadratic bezier arcs and lines. No image assets.

Closed Eye (masked, default)
Upper lid: quadratic bezier from (1, 8) to (15, 8) with control point (8, 3)
Lower lid: quadratic bezier from (1, 8) to (15, 8) with control point (8, 13)
Slash: diagonal line from (3, 3) to (13, 13)
Stroke: 1.5px, text_secondary color (hover: DASH_BLUE)
Open Eye (revealed, while held)
Upper lid: same bezier arc as closed
Lower lid: same bezier arc as closed
Pupil: filled circle at (8, 8), radius 2.5
No slash line
Color: DASH_BLUE (#008de4)
Simplified Alternative: Closed (circle + slash)
If bezier curves are awkward in egui's painter API.
Circle outline: center (8, 8), radius 6, stroke 1.5px
Slash: line from (3, 3) to (13, 13)
Simplified Alternative: Open (circle + pupil)
Circle outline: same as above
Pupil: filled circle at (8, 8), radius 2.5
No slash line

6. Interaction State Machine

  +-------------------+
  |  DEFAULT (masked)  |
  |  eye = closed      |
  |  color = secondary |
  +--------+----------+
           |
    pointer enters eye rect
           |
           v
  +-------------------+
  |  HOVER             |
  |  eye = closed      |
  |  color = DASH_BLUE |
  |  cursor = pointer  |
  |  tooltip shown     |
  +--------+----------+
           |
    mouse button down on eye
           |
           v
  +-------------------+
  |  REVEALING         |
  |  eye = open        |
  |  color = DASH_BLUE |
  |  text = plain      |
  +--------+----------+
           |
    mouse up OR pointer leaves eye rect
           |
           v
  +-------------------+
  |  DEFAULT (masked)  |  (returns to start)
  +-------------------+
